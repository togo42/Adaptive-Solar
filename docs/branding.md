# Adaptive Solar: Logo und Gestaltung

Das Logo verbindet eine goldene Sonne mit einem petrolfarbenen Solarmodul und einer ansteigenden türkisfarbenen Prognosekurve. Sonne und Modul stehen für PV-Physik, die Kurve für die lernende Prognose.

Die [PNG-Datei](../assets/adaptive-solar-logo.png) ist das Projektlogo für README und Projektvorstellungen. Der weiße Hintergrund sorgt für eine klare Darstellung auf hellen und dunklen Oberflächen. In der README wird das Logo mit 240 Pixeln Breite und beschreibendem Alternativtext eingebunden.

Ab Version 0.2.10 liegt eine unveränderte Kopie unter `custom_components/adaptive_solar/brand/icon.png`, damit die Integration ihr vorhandenes Markenbild auch mit HACS ausliefert. Es wird kein zweites Logo erzeugt.

Das Projektlogo steht, soweit urheberrechtlich geschützt, wie die übrigen eigenen
Projektinhalte unter `GPL-3.0-only`; siehe [Lizenzhinweis](../README.md#lizenz) und
[Lizenztext](../LICENSE). Seine Verwendung bedeutet keine offizielle Unterstützung
eines fremden Projekts oder einer veränderten Version durch Adaptive Solar.

Erstellt am 25.10.2026 mit dem eingebauten Imagegen-Werkzeug; kein CLI-/API-Fallback. Der finale Entwurf wurde auf Konturen, Lesbarkeit und Darstellung geprüft.

Finaler Generierungsprompt:

```text
Use case: logo-brand. Create the final app logo for Adaptive Solar, software for adaptive photovoltaic forecasts. One bold compact geometric symbol centered on a perfectly solid opaque white background. A golden amber rising half sun with five evenly spaced simple triangular rays above a dark teal two-row solar panel; an aqua upward-curving forecast line crosses the panel and ends in a circular data point. Smooth precise vector-like geometry and impeccable clean edges, solid flat colors, balanced generous white margins, square image. Small software-icon legibility. Absolutely no gradients, glow, textures, transparency, shadows, outlines, artifacts or scattered fragments. No text or letters, no mockup, no watermark. White negative spaces fully separate rays from sun and panel cells from each other.
```
